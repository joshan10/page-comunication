## 5. Modelo de Roman Jakobson — Comunicación (árbol)

```
                 (Copa) ── → Cción. No Verbal
                  🌳
                  ║   ← Func. Lenguaje
                  ║   ← Tipos
                (Raíces)
```

- **Copa del árbol:** Comunicación → deriva en la Acción No Verbal
- **Tronco:** representa las Funciones del lenguaje

## 8. Proceso Comunicativo — Modelo completo de Román Jakobson (Comunicación Asertiva)

### Proporción verbal / no verbal
- **7%** → Funciones del lenguaje (verbal)
- **93%** → Acción No Verbal

### Funciones del lenguaje (Modelo Jakobson)
| Función | Elemento asociado | Detalle |
|---|---|---|
| **Metalingüística** | Código | Estructura del lenguaje |
| **Poética** | — | Embellecer — Convenciones: Vestuario / Prendas, Saludo |
| **Fática** | Canal | Verificar — Paralenguaje |
| **Referencial** | Contexto | Base de la comunicación |
| **Apelativa** | R (Receptor) | Órdenes, Sugerencias, Emociones |
| **Emotiva** | E (Emisor) | Kinesis |

### Kinesis
```
Kinesis → Abierta / Cerrada → Seguridad
                             → Intensidad
```
